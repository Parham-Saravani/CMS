# CMS Dashboard

A lightweight and responsive CMS dashboard built with Vanilla JavaScript for managing users and products.

The project demonstrates practical front-end development concepts such as DOM manipulation, state management, local data persistence, theme switching, pagination, and user interaction handling.

## 📖 Overview

This project was developed as a portfolio application to practice and demonstrate JavaScript fundamentals through a real-world dashboard interface.

The dashboard allows users to manage products and users through a client-side CRUD workflow while providing a smooth user experience with theme switching, toast notifications, pagination, and persistent browser storage.

The interface is fully localized in Persian and optimized for RTL layouts.

## ⚙️ How It Works

* Users and products can be created, viewed, updated, and deleted directly from the dashboard.
* All data is stored locally in the browser using localStorage.
* Theme preferences are saved and restored automatically.
* Pagination updates dynamically based on available data.
* Toast notifications provide immediate feedback for user actions.
